# GUI 實機驗收清單

這份清單用於在真實 AutoCAD（`accoreconsole.exe`）下驗收 `main` 上的 GUI 與批次功能。

**自動測試不能取代這份清單。** 本專案的自動測試用假的 accoreconsole 或單一範例圖；下列項目從未在真實專案圖、真實 AutoCAD 下由人實際操作過。每個核取方塊在實際做完並符合「通過條件」後才可勾選，不得預先勾選。

基準版本：`main` 的 `1da900c`（PR #15 合併後）。驗收時請在文末紀錄表填入實際測的 commit。

## 0. 準備

- [ ] 把要用的真實 DWG **複製**到測試資料夾（例如 `D:\accept\in`），至少 6 份、檔名不同。**不要直接使用正式圖。**
- [ ] 輸出一律用另一個全新的空資料夾（例如 `D:\accept\out`），不要使用既有的 `output`。
- [ ] 記下輸入複本的雜湊：

```bash
cd "D:/accept/in" && sha256sum *.dwg > ../hash_before.txt
```

- [ ] 複製設定範本，並確認 `accoreconsole` 指向本機的 AutoCAD：

```bash
cp config.example.json config.json
```

  `config.json` 不進版本控制。環境列（① 基本設定）顯示找得到 accoreconsole 才能繼續。

- [ ] 啟動 GUI：

```bash
.venv/Scripts/python.exe app.py
```

## 1. 同時處理數（並行）

用「文字取代」，找一段**確定存在於圖上**的文字。若沒有命中，結果會是「變更 0 筆」，什麼都沒寫入，這次驗收無效。

- [ ] 「同時處理數」設 `1`，輸出到新資料夾，執行。**通過條件**：有輸出 DWG，變更筆數大於 0。
- [ ] 「同時處理數」設 `3`，輸出到另一個新資料夾，同一批圖、同樣條件。**通過條件**：結果 CSV 的內容與上一次一致（列的順序可以不同）。
- [ ] 設 `3` 執行時，另開終端機數 accoreconsole 程序。**通過條件**：同時有 3 個。

```bash
tasklist | grep -ci accoreconsole
```

- [ ] 設 `3` 執行中按「停止」。**通過條件**：所有 `accoreconsole.exe` 都結束，沒有殘留。
- [ ] 同時處理數填 `abc`、`0`、`99`。**通過條件**：分別當成 1、1、8。

## 2. 差異比對

- [ ] 舊版、新版各選一個資料夾（內含同名但內容不同的圖），輸出選新資料夾，執行。**通過條件**：`dwgdiff\diff_summary.csv` 有結果，`diff_details.csv` 列出實際的差異。
- [ ] 把輸出資料夾改成**舊版資料夾裡面**再執行。**通過條件**：被拒絕，訊息指出是「舊版」。
- [ ] 同樣測新版資料夾裡面。**通過條件**：被拒絕，訊息指出是「新版」。
- [ ] 舊版、新版各選單一檔案（DXF 或 DWG）。**通過條件**：可執行，不受資料夾重疊檢查影響。

## 3. 圖層標準檢查

- [ ] 使用預設的 `samples\layer_standard.csv` 執行。**通過條件**：產生 `layer_check\layer_check_report.html`，用瀏覽器打開內容可讀。
- [ ] 檢查 `layer_check_details.csv`、`layer_check_summary.csv` 存在，內容與圖面實際的圖層一致（抽查至少一筆）。

## 4. 圖框屬性

- [ ] 「圖框屬性匯出」：確認「圖框 Block 名稱」與圖面實際的圖框名稱相符，執行。**通過條件**：`titleblock_attrs.csv` 的圖框數大於 0。若為 0，代表名稱對不上，需先改名稱。
- [ ] 用 Excel 只修改一兩格屬性值並存檔，其他欄位不動。
- [ ] 「圖框屬性寫回」勾選「只預覽變更」。**通過條件**：`titleblock_results.csv` 的變更數等於修改的格數，輸出資料夾**沒有** DWG。
- [ ] 取消預覽，正式寫回。**通過條件**：輸出資料夾有 DWG，用 AutoCAD 打開後屬性值是新的，未修改的屬性不變。

## 5. 多任務

- [ ] 按「全選」。**通過條件**：開始按鈕顯示「（13）」。
- [ ] 勾三項（建議：DWG / DWT 版本表、文字擷取、圖層標準檢查）執行。**通過條件**：進度依序 1/3 → 2/3 → 3/3，結果區有三列摘要。
- [ ] 執行中按「停止」。**通過條件**：目前任務顯示已停止，尚未開始的任務顯示「略過（已停止）」，已完成的輸出保留。

## 6. 原圖沒有被改動

全部做完後：

```bash
cd "D:/accept/in" && sha256sum -c ../hash_before.txt
```

- [ ] **通過條件**：每一行都是 `OK`。

## 7. Revit 代理圖形（`PROXYGRAPHICS=0` 的真實專案圖）

前面各項用的圖，來源的 `PROXYGRAPHICS` 可能本來就是 1，那樣無法證明這項功能。

- [ ] 在 AutoCAD 打開一份**複本**，輸入 `PROXYGRAPHICS` 確認目前值為 `0`（若不是，改成 0 並存檔），放進輸入資料夾。
- [ ] 勾選「Revit 代理圖形」，輸出到新資料夾，執行。
- [ ] 檢查 `logs\proxygraphics_results.csv`。**通過條件**：原設定 `0`、新設定 `1`、存檔「已存檔」、輸出驗證「通過」、輸出值 `1`。
- [ ] 用 AutoCAD 打開**輸出**的 DWG，輸入 `PROXYGRAPHICS`。**通過條件**：值為 `1`。這是最終證據。
- [ ] 同一批再執行一次（不勾覆寫）。**通過條件**：全部「略過」，輸出檔的雜湊不變。
